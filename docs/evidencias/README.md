# Capturas reales - Reto 02 / Sesión 11

**Esta carpeta está vacía de capturas hasta que se ejecuten las pruebas.**
No se incluyen imágenes de ejemplo que simulen resultados.

1. Ejecuta cada caso de `../matriz-seguridad-spa-s11.md` en tu navegador.
2. Conserva la URL visible; cuando corresponda muestra F12 > Red o Aplicación.
3. **Oculta el JWT completo** y otros datos sensibles antes de guardar la imagen.
4. Guarda cada captura en esta carpeta con su ID, por ejemplo `I-03_red.png`.
5. Actualiza el campo *Resultado obtenido*, el estado y el nombre de evidencia en la matriz.
6. Si un caso falla, añade una ficha en `../informe-s11.md` con causa probable y solución.

G-01 a G-03, M-01, M-02, E-01 y B-01 a B-04 (24 en total).
